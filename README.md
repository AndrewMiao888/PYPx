# PYPx

## The Journey of Microplastics

A Nuxt 4 single-page IB PYP Year 5 exhibition site with an interactive particle-size explorer, a UV-weathering explainer, a one-hour household-materials model guide, and a first-party cookie notice.

### Start locally

```sh
npm install
npm run dev
```

The static logo and SVG favicon are in `public/`. Tailwind CSS 4 is configured through its official Vite plugin.
